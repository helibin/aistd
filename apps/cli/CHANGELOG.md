# Changelog

## [0.3.2] - 2026-11-24

### Changed

- 准备 GitHub 公开源码快照，记录固定规范的公开再分发范围及本地构建方式。
- 清理公开 Admin 模板中的演示令牌、登录标识和部分演示素材，保留上游许可证与固定归档校验。

## [0.3.1] - 2026-11-24

### Changed

- 为自有源码添加 MIT 许可证，明确内嵌规范与第三方模板的许可边界，并把安装和首次运行放到 README 首屏。

## [0.3.0] - 2026-11-18

### Added

- 新增独立 Admin 目标，可选择固定上游 Vben Naive UI 或 Soybean-admin 模板；支持终端向导、命令参数与 JSON。
- 创建时离线安装带许可证和来源哈希的模板源码；独立 pnpm 工作区接入 setup/check/build/run-admin 与静态部署入口，不混入现有 npm workspaces。

## [0.2.0] - 2026-11-17

### Added

- 交互式创建向导支持方向键选择、空格多选、步骤摘要及生成前确认；默认示例名 hello-aistd，取消操作不创建文件。

- 重复运行安装命令即可升级 CLI；下载、校验和运行检查通过后自动替换旧程序，失败保留旧版。

### Changed

- 新分支首次推送从默认分支共同祖先检查全部新增提交，避免漏查中间未升级版本的提交。

- 示例项目名统一为 `hello-aistd`，同步命令、配置与使用说明。

- CLI 版本、生成项目来源信息及发行目录统一读取 VERSION；提交须同步升级版本和 changelog。

## [0.1.0] - 2026-11-17

### Added

- 记录版本治理接入前的基线：多技术栈项目创建、已有项目接入、规范来源校验和 CLI 卸载。此日期为历史基线补录日期，不代表首次发布日期。
