# aistd 官网视觉规格 · revision 11

依据 AI Product Visual Design Standard v1.0。受众是新建或接入已有项目的开发者；平台为 React + Vite 构建的响应式静态 Web；主要路径是安装 CLI、选择新建或接入命令，再按需调整配置。站点使用固定主题：深色品牌与使用区搭配浅色配置区；不随系统切换暗色，以保证品牌画面和代码阅读的稳定性。最终用户只通过安装脚本获取 CLI，不提供源码构建入口。

## 方向决定

- A 中性文档型：上版采用，信息清楚，但首屏缺乏品牌辨识度和产品画面。
- B 展示型：大面积图像与口号，容易遮盖“未公开发行”的事实。
- C 系统图景型：上一版采用。深墨色全宽首屏与实时生成关系图有辨识度，但 CLI 产物缺少直观展示。
- D 产品实物型：本版采用。参考 Onorca 官网居中的品牌叙事、深色留白、醒目的单一操作和首屏可见的产品画面；aistd 展示自身真实命令与生成目录，不借用对方品牌、截图、文案或下载能力。

品牌关键词：精确、可信、开阔、克制。排除无证据的统计、装饰卡片墙、模糊渐变和无关图库照片。首屏可切换的新建/接入预览列出 CLI 实际命令与生成文件，作为产品画面而非虚构桌面客户端；低对比度 Canvas 退为背景纹理。

## 页面与层级

- 首屏：品牌由页头字标承担，首屏不再重复放大的 `aistd.`。第一视觉信号是两行的价值主张；上行元信息以 CLI 版本与规范版本说明身份，句末冰蓝句点承接品牌符号。页头使用白底“安装 / 升级 CLI”入口，手机保留该按钮并隐藏“开始使用”导航项。已配置安装入口时首屏主操作为“安装 / 升级 CLI”，点击复制安装命令，否则指向安装说明；次操作进入配置。首屏安装命令使用深色面、细边框和冰蓝代码提升可见度，下方说明复制到终端执行与重复执行即可升级。下方真实 CLI 产物预览可切换新建与已有项目。
- 开始使用：先展示环境配置的安装/升级入口 `#install`，说明新版验证成功后自动替换、失败保留旧版，再以两条全宽行给出 `create --name` 与 `init --dir .`；同区说明 `doctor` 的校验边界。
- 配置：可选工具面板；左侧按服务与网页、后台管理、移动 App、小程序分组，提供七个独立目标、对应技术栈和视觉草稿开关。默认勾选 API / Web，Admin 默认关闭。启用目标后显示原生下拉框：后端 Go / NestJS、Web React / Vue、Admin Vben Naive UI / Soybean-admin、移动端 React Native / Expo 或 Flutter、小程序 Taro / uni-app；同一家族共用一次选择。Admin 生成独立 pnpm 工作区，需 Node.js 22.18+，通过 make setup / make run-admin 安装和启动；模板演示的登录与权限需另行接入业务后端。关闭家族时隐藏下拉框并保留选择，命令与 JSON 省略该技术栈；重新启用后恢复。右侧优先显示可复制的 CLI 命令，JSON 置于可展开区域。
- 规范与文档：两条规范行、五个文档标签页（含 `aistd uninstall` 的 CLI 卸载说明）；安装地址由 `AISTD_INSTALL_URL` 在 Docker 启动时注入，未配置时不显示可复制的安装命令。

宽屏内容最大 1320px，侧边留白 48px；1000px 以下 32px，760px 以下 20px。Hero 本身全宽，桌面高度按可视视口减去 172px、最多 780px；手机减去 160px，让下一段标题进入首屏。产物预览在手机改为纵向，首屏露出工具顶部；窄屏配置面板改为上下结构，文档标签页可横向滚动。

## Tokens 与组件

三层颜色、字体、间距与组件值见 `design/tokens/site.json`，网页映射见 `apps/web/src/styles.css`。正文采用系统 UI 字体及 PingFang SC / Microsoft YaHei 回退；代码采用系统等宽字体。桌面品牌字 96px、章节标题 48px；手机分别为 72px 和 34px；正文 16px，表单说明 12–14px。首屏主张桌面 84px、手机 40px，是页面最大的文字层级；句末句点使用冰蓝强调色。字距保持 0（首屏主张 -0.02em 用于收紧两行）。黑白承担主层级，冰蓝标记代码与状态，操作面维持白色背景。

主按钮 48px 高，手机 Hero 按钮至少 44px；输入框与技术栈下拉框 52px；工具边界半径 6px；可见焦点轮廓 2px。每个下拉框使用关联的文字标签和说明。输入错误以文字和 `aria-invalid` 同时提示；没有应用目标或名称非法时禁用命令复制与 JSON 下载。复制失败显示状态消息。预览模式用 `aria-pressed` 标示；文档标签页有选中态与方向键操作。配置下载是同步本地生成，不展示虚构的加载态。页面无图片请求；Canvas 遵守 `prefers-reduced-motion`。首屏静态资源 gzip 预算 100KB，不含 CLI 发行物。
